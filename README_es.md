# ESTRELLA
Este sitio web presenta los productos finales del proyecto ESTRELLA de la NSF (subvención NSF n.º 1949230). 

Incluimos cuatro conjuntos de lecciones:
* [Visualizar operaciones con fracciones usando Python y videos digitales (6.º grado)](https://github.com/pattichis/fractions/blob/main/README_es.md)
* [Visualizar relaciones lineales usando Python y videos digitales (7.º grado)](https://github.com/pattichis/GraphSpeeds2/blob/main/README_es.md)
* [Visualizar la geometría de rectas usando Python (9.º o 10.º grado)](https://github.com/pattichis/lineart/blob/main/README_es.md)
* [Visualizar funciones exponenciales usando Python y videos: hacer una flor y una cara con exponenciales (9.º grado)](https://github.com/pattichis/graphfuns2/blob/main/README_es.md)
  
## [Lecciones: visualizar operaciones con fracciones usando Python y videos digitales (6.º grado)](https://github.com/pattichis/fractions/blob/main/README_es.md)
El proyecto final consiste en crear un video para visualizar la multiplicación y la división de fracciones.

Este es un ejemplo hecho por los estudiantes. A diferencia de los otros proyectos de abajo, en este ejemplo los estudiantes agregaron su propio audio y algunos cuadros adicionales. El audio original se reemplazó con audio generado por IA.

## [Lecciones: visualizar funciones exponenciales usando Python y videos: hacer una flor y una cara con exponenciales (9.º grado)](https://github.com/pattichis/graphfuns2/blob/main/README_es.md)
Las actividades incluyen dos proyectos. En el primer proyecto, los estudiantes tienen que hacer una flor usando funciones exponenciales.
En el segundo proyecto, los estudiantes tienen que hacer una cara usando funciones exponenciales.
